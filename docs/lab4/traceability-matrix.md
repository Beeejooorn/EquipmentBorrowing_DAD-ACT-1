# Lab 4 – Traceability Matrix (use case → implementation → evidence)

Each row follows one required use case through the code to the evidence that proves it works. "A0x" refers to the Appendix C scenario; the full setup / expected / observed write-up for each one is in [`verification-evidence.md`](verification-evidence.md).
